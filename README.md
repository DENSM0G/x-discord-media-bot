# x-discord-media-bot

Self-hosted Discord-бот и лёгкий веб-архив для автоматического скачивания и публикации медиафайлов из постов **X (ранее Twitter)**.

## О проекте

Я задумал этот проект как эксперимент, потому-что мне не понравились решения вроде *SaucyBot*, которые зачастую обрезают посты-карусели на 4-м файле, хотя в X давно можно прикреплять до 20 фото и видео в одном посте. Мне хотелось получить полностью автономный инструмент под свой домашний сервер (Proxmox), без зависимости от сторонних публичных API и с нормальной веб-галереей для просмотра оригиналов без сжатия.

**Как это создавалось:** вся архитектура, пользовательские сценарии, логика работы хранилища и техническое задание спроектированы мной, а программный код написан в паре с ИИ (**Google Gemini**).

## Основные возможности

* **100% локальный парсинг:** извлечение медиа напрямую через `gallery-dl` (с автоматическим переключением на `yt-dlp` при сбоях). Поддерживается до 20 вложений в посте в исходном порядке и качестве (`orig`), включая посты с возрастным ограничением (через ваш `cookies.txt`).
* **Отправка в Discord:**
  * Ссылки на `x.com`, `twitter.com` и зеркала (`fxtwitter`, `vxtwitter`, `fixupx`) перехватываются автоматически, а комментарий пользователя сохраняется в ответе бота.
  * Сначала отправляется ссылка на веб-страницу с оригиналами и краткая инструкция, следом — сами медиафайлы батчами по 10 штук (лимит Discord API), после чего исходное сообщение пользователя удаляется.
  * Видео, превышающие лимит размера сервера Discord, автоматически сжимаются во временной папке через `ffmpeg` (`libx265`) под доступный порог и удаляются из `/tmp` сразу после отправки.
* **Адаптивная веб-галерея оригиналов (`FastAPI`):**
  * Раскладка подстраивается под формат поста: одиночный режим, сетка 2–4 кадра (как в X), вертикальная лента для комиксов/длинных скриншотов или горизонтальная карусель для больших подборок, а видео со звуком выносятся отдельным блоком снизу. (карусель текущий момент работает плохо)
  * Для мгновенного открытия страницы сначала загружаются лёгкие `WebP`-превью, а оригиналы подгружаются фоном в кэш браузера для моментального открытия в Lightbox.
* **Самомодерация в чате:** автор запроса может удалить сообщения бота (и файлы с сервера) одним нажатием на реакцию `❌` под ответом.
* **Автономное управление диском и самодиагностика:**
  * Каждый запрос сохраняется в папку формата `YYYY-MM-DD_HH-MM-SS_SSS`.
  * При нехватке свободного места на разделе автоматически удаляются самые старые запросы (FIFO), а соответствующие сообщения в Discord помечаются статусом об удалении файлов.
  * При каждом запуске сервиса выполняется аудит целостности папок и пересборка индекса маршрутов.
* **Дружелюбность к VPN и Reverse Proxy:** поддержка локального `SOCKS5`/`HTTP`-прокси для исходящего трафика бота без изменения системных маршрутов контейнера (входящий трафик от Nginx Proxy Manager работает напрямую).

## Стек технологий

* **Backend и бот:** Python 3.11+, `discord.py`, `FastAPI`, `uvicorn`, `Jinja2`, `aiohttp-socks`
* **Извлечение и обработка медиа:** `gallery-dl`, `yt-dlp`, `ffmpeg` / `ffprobe`, `Pillow`
* **Frontend:** нативный HTML5 / CSS3 / Vanilla JS

## Быстрое развертывание (Debian / Ubuntu / Proxmox LXC)

### 1. Подготовка бота в Discord Developer Portal
1. Создайте приложение в [Discord Developer Portal](https://discord.com/developers/applications) и скопируйте токен на вкладке **Bot**.
2. В разделе **Privileged Gateway Intents** обязательно включите **Message Content Intent**.
3. Пригласите бота на сервер со следующими правами: `View Channels`, `Send Messages`, `Send Messages in Threads`, `Manage Messages`, `Embed Links`, `Attach Files`, `Read Message History`, `Add Reactions`.

### 2. Установка в LXC-контейнер
Склонируйте репозиторий и запустите скрипт автоматической установки (он установит `python3-venv`, `ffmpeg`, создаст окружение и зарегистрирует службу `systemd`):

```bash
apt update && apt install -y git sudo
git clone [https://github.com/DENSM0G/x-discord-media-bot.git](https://github.com/DENSM0G/x-discord-media-bot.git) /opt/x-discord-media-bot
cd /opt/x-discord-media-bot
chmod +x scripts/*.sh
./scripts/install.sh
```

### 3. Конфигурация
Отредактируйте созданный файл `.env` (известна ошибка с отображением кириллицы, для исправления перейдите на UTF-8):

```bash
nano /opt/x-discord-media-bot/.env
```

Основные параметры:
```env
DISCORD_TOKEN=ваш_токен_бота
PUBLIC_BASE_URL=[https://sub.domain.duckdns.org](https://sub.domain.duckdns.org)
WEB_HOST=0.0.0.0
WEB_PORT=8080
PROXY_URL=socks5://127.0.0.1:1080
MIN_FREE_SPACE_GB=5.0
VIDEO_CODEC=libx265
```

*(Опционально)* Для доступа к постам с возрастным ограничением экспортируйте cookies из браузера (где выполнен вход в аккаунт X) в формате Netscape и сохраните их в файл `/opt/x-discord-media-bot/config/cookies.txt`.

### 4. Запуск и обновление
Запуск службы и просмотр логов:
```bash
systemctl start x-discord-bot
journalctl -u x-discord-bot -f
```

Для обновления кода и экстракторов (`gallery-dl` / `yt-dlp`) до свежих версий используйте встроенный скрипт:
```bash
cd /opt/x-discord-media-bot
./scripts/update.sh
```

## Структура проекта

```text
x-discord-media-bot/
├── app/
│   ├── main.py              # Точка входа: аудит диска, запуск FastAPI и Discord-бота
│   ├── config.py            # Загрузка параметров из .env
│   ├── bot.py               # Логика Discord: очередь, батчинг, самомодерация по ❌
│   ├── extractor.py         # Обертка над gallery-dl и yt-dlp
│   ├── media_processor.py   # Классификация GIF/Video, сжатие H.265, WebP-превью
│   ├── storage.py           # Управление папками, index.json, аудит и FIFO-очистка
│   └── web.py               # Маршруты веб-галереи и потоковая раздача медиа
├── web/
│   ├── templates/           # HTML-шаблоны (gallery.html, gone.html)
│   └── static/              # Стили и JS (Lightbox, предзагрузка оригиналов)
├── scripts/
│   ├── install.sh           # Первичная установка и настройка systemd
│   └── update.sh            # Обновление из Git и апдейт парсеров
└── config/                  # Директория для cookies.txt
```
