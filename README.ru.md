# x-discord-media-bot

Self-hosted Discord-бот и лёгкий веб-архив для автоматического скачивания и публикации медиафайлов из постов **X (ранее Twitter)**.

## О проекте

Я задумал этот проект как автономную замену публичным ботам вроде *SaucyBot*, которые (в текущий момент) обрезают посты-карусели на 4-м файле, хотя в X давно можно прикреплять до 20 фото и видео в одном посте. Мне нужен был полностью локальный инструмент под домашний сервер (Proxmox LXC) без зависимости от сторонних публичных API, с публикацией от имени отправителя и быстрой веб-галереей.

**Как это создавалось:** вся архитектура, пользовательские сценарии, защита ресурсов и техническое задание спроектированы мной, а программный код написан в паре с нейросетью (**Google Gemini**).

## Основные возможности

* **100% локальное извлечение медиа:**
  * Прямое скачивание оригиналов через `gallery-dl` (с автоматическим откатом на `yt-dlp` при сбоях).
  * Поддержка до 20 вложений в исходном порядке и качестве, включая посты с возрастным ограничением (через `cookies.txt`).
  * **Умная обработка твитов-цитат (Quote Tweets):** если у основного поста есть свои медиа — скачиваются только они; если своих нет, бот забирает медиа из цитируемого поста и указывает исходного автора (`↪ Quoted media from @author`).
* **Публикация в Discord через Вебхуки:**
  * Сообщения отправляются с **локальным серверным ником и аватаркой пользователя-отправителя** (поддерживаются как обычные каналы, так и ветки/Threads; при отсутствии права `Manage Webhooks` бот откатывается на обычные сообщения).
  * **Умная фильтрация комментариев:** сообщения с текстом длиннее `MAX_COMMENT_LENGTH` (по умолчанию 50 символов) игнорируются. При подсчёте длины исключаются **все** ссылки, при этом **сторонние ссылки (не на X)** аккуратно сохраняются в сообщении бота.
  * Вывод счётчика ссылок (`1/3`), автора и описания поста из X (с безопасным усечением под лимит Discord в 2000 символов и резервом под будущую метку удаления), статистики (лайки, репосты, ответы, просмотры) с динамическим временем `<t:...:f>`, а также ссылок на веб-архив и оригинальный пост в X.
  * Превью веб-страницы подавляется в сообщении бота угловыми скобками `<...>`, но OpenGraph-теги сохраняются — при пересылке «голой» ссылки в другой канал Discord сам построит карточку предпросмотра.
  * Автоматические реакции **`❌`** (удаление поста автором или модератором) и **`🩶`** (удобный лайк).
* **Автовоспроизведение GIF и современные кодеки:**
  * Беззвучные MP4-гифки из X автоматически пересобираются через `ffmpeg` (с генерацией палитры) в настоящие зацикленные **`.gif`** для вложений Discord, чтобы они воспроизводились в чате сами, а на сервере для веб-галереи остаётся плавный оригинальный `.mp4`. Если гифка не влезает в лимит сервера, выполняется откат на MP4/видео.
  * Тяжёлые видео сжимаются во временной папке современными кодеками (**AV1 `libsvtav1`**, **VP9 `libvpx-vp9`** или **HEVC `libx265`**) с настраиваемым пресетом качества (`VIDEO_PRESET`), а тяжёлые фото — в **WebP** (без JPEG-«лесенок» на градиентах).
  * Перед отправкой выполняется повторная проверка точного веса каждого файла, батчи автоматически дробятся при ошибке HTTP 413, а сверхдлинные видео, которые невозможно ужать без критической потери качества, пропускаются с уведомлением и ссылкой на оригинал.
* **Веб-галерея с 4 режимами отображения (`FastAPI` + Vanilla JS):**
  * Выводит **полный, несокращённый** текст поста с кликабельными ссылками, статистикой и кнопкой потокового скачивания всех оригиналов одним архивом **`Download all (.zip)`** без записи лишней копии на диск и с постоянным расходом RAM.
  * **4 режима просмотра:** `Carousel` (бесшовная горизонтальная карусель с колёсиком, свайпом, скроллбаром и кнопками + видео ниже), `Comic` (строгий оригинальный порядок сверху вниз), `Smart Tiles` (сбалансированная Masonry-сетка с сохранением пропорций + видео ниже) и `Grid` (квадратная сетка с динамическим расчётом колонок под пропорции экрана и плотность пикселей, видео открываются только в полноэкранном Lightbox).
  * Мгновенная загрузка лёгких **WebP-превью** с фоновой предзагрузкой оригиналов для быстрого открытия в Lightbox.
  * **Динамический подвал:** в реальном времени показывает свободное место на диске, запас до очистки и точное место текущего поста в очереди FIFO на удаление (обновляется через `/status`).
* **Очереди, стабильность и защита ресурсов:**
  * Строгий `asyncio.Lock` на каждый канал и ветку исключает перемешивание сообщений при быстрой отправке подряд, при этом разные каналы работают параллельно (до `MAX_CONCURRENT_JOBS`).
  * Персистентная дисковая очередь (`data/queue.json`) автоматически подхватывает незавершённые задачи после перезапуска службы.
  * Контроль свободной оперативной памяти через `/proc/meminfo` (`MIN_FREE_RAM_MB`) и запуск `ffmpeg` с пониженным приоритетом (`nice -n 10`) защищают контейнер от OOM Killer.
  * Автоматическая FIFO-очистка старых папок при снижении свободного места ниже `MIN_FREE_SPACE_GB` редактирует сообщение вебхука в Discord, добавляя метку `` `deleted from bot server:` <t:...:f> ``.
* **Поддержка исходящего прокси:** опциональная маршрутизация исходящих запросов к Discord и X через SOCKS5/HTTP-прокси (с поддержкой удалённого DNS) без влияния на входящий трафик веб-галереи.

## Стек технологий

* **Backend и бот:** Python 3.11+, `discord.py`, `FastAPI`, `uvicorn`, `Jinja2`, `aiohttp-socks`
* **Извлечение и обработка медиа:** `gallery-dl`, `yt-dlp`, `ffmpeg` / `ffprobe`, `Pillow`
* **Frontend:** нативный HTML5 / CSS3 / Vanilla JS (без фреймворков и внешних CDN)

## Быстрое развертывание (Debian / Ubuntu / Proxmox LXC)

### 1. Подготовка бота в Discord Developer Portal
1. Создайте приложение в [Discord Developer Portal](https://discord.com/developers/applications) и скопируйте токен на вкладке **Bot**.
2. В разделе **Privileged Gateway Intents** включите **Message Content Intent**.
3. Пригласите бота на сервер со следующими правами:
   `View Channels`, `Send Messages`, `Send Messages in Threads`, `Manage Messages`, `Manage Webhooks`, `Embed Links`, `Attach Files`, `Read Message History`, `Add Reactions`.

### 2. Установка в LXC-контейнер
Склонируйте репозиторий и запустите скрипт установки (поставит `python3-venv`, `ffmpeg`, настроит локаль `en_US.UTF-8`, отключит отслеживание `fileMode` в Git и зарегистрирует службу `systemd`):

```bash
apt update && apt install -y git
git clone [https://github.com/DENSM0G/x-discord-media-bot.git](https://github.com/DENSM0G/x-discord-media-bot.git) /opt/x-discord-media-bot
cd /opt/x-discord-media-bot
bash scripts/install.sh
```

### 3. Конфигурация
Отредактируйте файл `/opt/x-discord-media-bot/.env`:

```bash
nano /opt/x-discord-media-bot/.env
```

Основные параметры (полный список с комментариями — в `.env.example`):

```env
DISCORD_TOKEN=ваш_токен_бота
PUBLIC_BASE_URL=[https://sub.domain.duckdns.org](https://sub.domain.duckdns.org)
WEB_HOST=0.0.0.0
WEB_PORT=8080
PROXY_URL=socks5://127.0.0.1:1080

MIN_FREE_SPACE_GB=5.0
MIN_FREE_RAM_MB=512
MAX_CONCURRENT_JOBS=2
MAX_COMMENT_LENGTH=50

DEFAULT_VIEW_MODE=carousel
VIDEO_CODEC=libsvtav1
VIDEO_PRESET=4
```

*(Опционально)* Для доступа к постам с возрастным ограничением экспортируйте cookies из браузера (где выполнен вход в X) в формате Netscape и сохраните их в `/opt/x-discord-media-bot/config/cookies.txt`.

### 4. Запуск и обновление
Запуск службы и просмотр логов:

```bash
systemctl start x-discord-bot
journalctl -u x-discord-bot -f
```

Обновление кода и экстракторов (`gallery-dl` / `yt-dlp`):

```bash
cd /opt/x-discord-media-bot
bash scripts/update.sh
```

## Структура проекта

```text
x-discord-media-bot/
├── app/
│   ├── main.py              # Точка входа: очистка /tmp, аудит диска, запуск FastAPI и бота
│   ├── config.py            # Загрузка и валидация параметров из .env
│   ├── bot.py               # Логика Discord: вебхуки, локи по каналам, реакции, пометки FIFO
│   ├── extractor.py         # Фильтр сообщений, обертка gallery-dl/yt-dlp, Quote Tweets и статистика
│   ├── media_processor.py   # Контроль RAM, ffprobe, WebP-превью, конвертация GIF, сжатие AV1/VP9/HEVC
│   ├── storage.py           # Папки постов, queue.json, index.json, аудит и FIFO-очистка
│   └── web.py               # Маршруты FastAPI, OpenGraph, API статуса, потоковый ZIP
├── web/
│   ├── templates/           # HTML-шаблоны Jinja2 (gallery.html, gone.html)
│   └── static/              # Стили и Vanilla JS (4 режима, Lightbox, живой подвал)
├── scripts/
│   ├── install.sh           # Зависимости, локаль UTF-8 и настройка systemd
│   └── update.sh            # Обновление из Git и апдейт парсеров
├── config/                  # Директория для cookies.txt
├── .env.example             # Шаблон конфигурации
├── README.md                # Документация на английском
└── README.ru.md             # Документация на русском
```
