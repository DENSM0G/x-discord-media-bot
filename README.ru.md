# x-discord-media-bot

Self-hosted Discord-бот и лёгкий веб-архив для автоматического скачивания и публикации медиафайлов из постов **X (ранее Twitter)**.

## О проекте

Я задумал этот проект как автономную замену публичным ботам вроде *SaucyBot*, которые обрезают посты-карусели на 4-м файле, хотя в X давно можно прикреплять до 20 фото и видео в одном посте. Мне нужен был полностью локальный инструмент под домашний сервер (Proxmox LXC / Linux) без зависимости от сторонних публичных API, с публикацией от имени отправителя и быстрой веб-галереей.

**Как это создавалось:** вся архитектура, пользовательские сценарии, защита ресурсов и техническое задание спроектированы мной, а программный код написан в паре с нейросетью (**Google Gemini**).

## Основные возможности

* **100% локальное извлечение медиа:**
  * Прямое скачивание оригиналов через `gallery-dl` (с автоматическим откатом на `yt-dlp` при сбоях).
  * Поддержка до 20 вложений в исходном порядке и качестве, включая посты с возрастным ограничением (через `cookies.txt`).
  * **Умная обработка твитов-цитат (Quote Tweets):** если у основного поста есть свои медиа — скачиваются только они; если своих нет, бот забирает медиа из цитируемого поста и указывает исходного автора (`↪ Quoted media from @author`).
* **Публикация в Discord через Вебхуки:**
  * Сообщения отправляются с **локальным серверным ником и аватаркой пользователя-отправителя** (поддерживаются как обычные каналы, так и ветки/Threads; при отсутствии права `Manage Webhooks` бот откатывается на обычные сообщения).
  * **Умная фильтрация комментариев:** сообщения с текстом длиннее `MAX_COMMENT_LENGTH` (по умолчанию 50 символов) игнорируются. При подсчёте длины исключаются **все** ссылки, при этом **сторонние ссылки (не на X)** аккуратно сохраняются в сообщении бота.
  * Вывод счётчика ссылок (`1/3`), автора и описания поста из X (с безопасным усечением под лимит Discord в 2000 символов и резервом под будущую метку удаления), статистики (лайки, репосты, ответы, просмотры) с динамическим временем `<t:...:f>`, а также ссылок на веб-архив и оригинальный пост в X.
  * Превью веб-страницы подавляется в сообщении бота угловыми скобками `<...>`, но OpenGraph-теги сохраняются — при пересылке «голой» ссылки в другой канал Discord сам построит карточку предпросмотра.
  * Автоматические реакции **`❌`** (удаление поста автором или модератором) и **`🩶`** (удобный лайк).
* **Автовоспроизведение GIF и современные кодеки:**
  * Беззвучные MP4-гифки из X автоматически пересобираются через `ffmpeg` (с генерацией палитры) в настоящие зацикленные **`.gif`** для вложений Discord, чтобы они воспроизводились в чате сами, а на сервере для веб-галереи остаётся плавный оригинальный `.mp4`.
  * Тяжёлые видео сжимаются во временной папке современными кодеками (**AV1 `libsvtav1`**, **VP9 `libvpx-vp9`** или **HEVC `libx265`**) с настраиваемым пресетом качества (`VIDEO_PRESET`), а тяжёлые фото — в **WebP** (без JPEG-«лесенок» на градиентах).
  * Перед отправкой выполняется повторная проверка точного веса каждого файла, батчи автоматически дробятся при ошибке HTTP 413, а сверхдлинные видео пропускаются с уведомлением и ссылкой на оригинал.
* **Веб-галерея с 4 режимами отображения (`FastAPI` + Vanilla JS):**
  * Выводит **полный, несокращённый** текст поста с кликабельными ссылками, статистикой и кнопкой асинхронного потокового скачивания всех оригиналов одним архивом **`Download all (.zip)`** без записи лишней копии на диск и с постоянным расходом RAM.
  * **4 режима просмотра:** `Carousel`, `Comic`, `Smart Tiles` (Masonry) и `Grid` (квадратная сетка с динамическим расчётом колонок под экран и плотность пикселей, видео открываются только в полноэкранном Lightbox).
  * Мгновенная загрузка лёгких **WebP-превью** с фоновой предзагрузкой оригиналов для быстрого открытия в Lightbox.
  * **Динамический подвал (опционально):** в реальном времени показывает свободное место на диске, запас до очистки и точное место поста в очереди FIFO (отключается через `SHOW_STORAGE_STATUS=false`).
* **Безопасность, изоляция и защита ресурсов:**
  * **Изоляция привилегий:** `scripts/install.sh` запускает службу от бесправного системного пользователя `xbot` с песочницей `systemd` (`NoNewPrivileges`, `ProtectSystem=strict`, `PrivateTmp`), закрывает `.env` правами `600` (только `root`) и вычищает `DISCORD_TOKEN` из окружения дочерних процессов `ffmpeg`/`gallery-dl`/`yt-dlp`.
  * **Живая квота диска и динамическая FIFO-очистка:** во время скачивания отслеживается свободное место и размер текущего поста (`MAX_POST_DISK_PERCENT`, по умолчанию `50%` от доступного боту бюджета диска); при нехватке места старые посты удаляются на лету, а при превышении лимита загрузка прерывается с уведомлением в чат.
  * **Контроль доступа и защита веба:** личные сообщения боту отключены по умолчанию (`ALLOW_DMS=false`), есть белый список серверов (`ALLOWED_GUILD_IDS`), строгий белый список раздачи медиа (закрывает доступ к `meta.json`), лимит параллельных ZIP-загрузок на IP (`MAX_CONCURRENT_DOWNLOADS_PER_IP=10`), опциональная блокировка прямого доступа к порту `8080` в обход `TRUSTED_PROXY_IPS` (`RESTRICT_WEB_TO_TRUSTED_PROXIES`) и защитные HTTP-заголовки (`nosniff`, `no-referrer`, `SAMEORIGIN`).
  * **Очереди и защита RAM:** строгий `asyncio.Lock` на каждый канал/ветку, персистентная очередь `data/queue.json`, контроль `/proc/meminfo` (`MIN_FREE_RAM_MB`) и приоритет `nice -n 10` для `ffmpeg`.
* **Поддержка VPN-прокси и Reverse Proxy:** исходящий трафик Discord и X (включая DNS-запросы через `socks5h://` / `rdns=True`) направляется через локальный `SOCKS5`/`HTTP`-прокси, не затрагивая входящий трафик веб-галереи от Nginx Proxy Manager.

## Стек технологий

* **Backend и бот:** Python 3.11+, `discord.py`, `FastAPI`, `uvicorn`, `Jinja2`, `aiohttp-socks`
* **Извлечение и обработка медиа:** `gallery-dl`, `yt-dlp`, `ffmpeg` / `ffprobe`, `Pillow`
* **Frontend:** нативный HTML5 / CSS3 / Vanilla JS (без фреймворков и внешних CDN)

## Системные требования

Проверено в минимальном LXC-контейнере Debian/Ubuntu:

* **Минимальные:** 1 vCPU, 1 ГБ RAM, 3 ГБ на диске (~2,2 ГБ занимает ОС и окружение бота + ~800 МБ остаётся под медиафайлы, чего хватает на 200+ постов при установке `MIN_FREE_SPACE_GB=0.5`).
* **Рекомендуемые:** 2+ vCPU, 2 ГБ RAM, от 20 ГБ на диске (для более быстрого перекодирования видео в AV1/HEVC и хранения большего архива оригиналов).
* **ОС:** Debian 12+, Ubuntu 22.04+ или другой совместимый дистрибутив Linux с Python 3.11+ и `ffmpeg`.

> **Совет для конфигурации с 1 vCPU / 1 ГБ RAM / 3 ГБ диска:** укажите в `.env` параметры `MIN_FREE_SPACE_GB=0.5`, `MAX_CONCURRENT_JOBS=1` и `MIN_FREE_RAM_MB=256`, а для ускорения сжатия видео на одном ядре используйте `VIDEO_PRESET=6` (либо `VIDEO_CODEC=libx265` с `VIDEO_PRESET=medium`).

## Быстрое развертывание (Debian / Ubuntu / Proxmox LXC)

### 1. Подготовка бота в Discord Developer Portal
1. Создайте приложение в [Discord Developer Portal](https://discord.com/developers/applications) и скопируйте токен на вкладке **Bot** (отключите **Public Bot**, если бот личный).
2. В разделе **Privileged Gateway Intents** включите **Message Content Intent**.
3. Пригласите бота на сервер со следующими правами:
   `View Channels`, `Send Messages`, `Send Messages in Threads`, `Manage Messages`, `Manage Webhooks`, `Embed Links`, `Attach Files`, `Read Message History`, `Add Reactions`.

### 2. Установка в LXC-контейнер
Склонируйте репозиторий и запустите скрипт установки (создаст изолированного пользователя `xbot`, поставит `python3-venv` и `ffmpeg`, настроит локаль `en_US.UTF-8`, права на файлы и службу `systemd`):

```bash
apt update && apt install -y git
git clone [https://github.com/DENSM0G/x-discord-media-bot.git](https://github.com/DENSM0G/x-discord-media-bot.git) /opt/x-discord-media-bot
cd /opt/x-discord-media-bot
bash scripts/install.sh
```

### 3. Конфигурация
Отредактируйте файл `/opt/x-discord-media-bot/.env`:

```bash
nano /opt/x-discord-media-bot/.env
```

Основные параметры (полный список с комментариями — в `.env.example`):

```env
DISCORD_TOKEN=ваш_токен_бота
PUBLIC_BASE_URL=[https://sub.domain.duckdns.org](https://sub.domain.duckdns.org)
WEB_HOST=0.0.0.0
WEB_PORT=8080
PROXY_URL=socks5://127.0.0.1:1080

MIN_FREE_SPACE_GB=5.0
MAX_POST_DISK_PERCENT=50
MIN_FREE_RAM_MB=512
MAX_CONCURRENT_JOBS=2

ALLOW_DMS=false
ALLOWED_GUILD_IDS=
MAX_COMMENT_LENGTH=50

DEFAULT_VIEW_MODE=carousel
SHOW_STORAGE_STATUS=true
MAX_CONCURRENT_DOWNLOADS_PER_IP=10
TRUSTED_PROXY_IPS=127.0.0.1,::1
RESTRICT_WEB_TO_TRUSTED_PROXIES=false

VIDEO_CODEC=libsvtav1
VIDEO_PRESET=4
```

*(Опционально)* Для доступа к постам с возрастным ограничением экспортируйте cookies из браузера (где выполнен вход в X) в формате Netscape, сохраните их в `/opt/x-discord-media-bot/config/cookies.txt` и ограничьте права:

```bash
chown root:xbot /opt/x-discord-media-bot/config/cookies.txt
chmod 640 /opt/x-discord-media-bot/config/cookies.txt
```

### 4. Запуск и обновление
Запуск службы и просмотр логов:

```bash
systemctl start x-discord-bot
journalctl -u x-discord-bot -f
```

Обновление кода и экстракторов (`gallery-dl` / `yt-dlp`):

```bash
cd /opt/x-discord-media-bot
bash scripts/update.sh
```
